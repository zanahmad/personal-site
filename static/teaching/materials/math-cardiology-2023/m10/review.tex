\section*{Local image filters and learned classification --- review sheet}
Use this after attempting the worked examples and practice. Explain each claim in words before calculating.

\section*{Key ideas}
\begin{itemize}
\item A local filter map is different from an image label.
\item Weight sharing reuses a local rule; pooling deliberately loses location information.
\item This demonstration fits class centers, not convolutional filters.
\item Report held-out results and predeclared failures with the scope of the generator.
\end{itemize}
\section*{Common errors and repairs}
\textbf{A fixed-filter demo trained a CNN.} Only its output class centers were fitted; convolutional weights stayed fixed.

\textbf{Perfect synthetic accuracy proves medical usefulness.} It describes a simple same-generator test, not clinical evidence.

\textbf{Every image augmentation preserves the label.} Check the target: rotating wide/tall images swaps their labels.
