\section*{Key ideas}
\begin{itemize}
\item Low error can follow from exact representability.
\item Retained modes and parameter ranges define the baseline contract.
\item Mean preservation does not imply field accuracy.
\item Graph normalization and basis conventions affect interpretation.
\item Research analogy is different from reproduction.
\end{itemize}
\section*{Common errors and repairs}
\textbf{Treating finer-grid evaluation as new-physics evidence.} Keep representation and physical-parameter tests separate.

\textbf{Assuming an unexcited mode has a fitted gain of zero.} It is unidentifiable without additional assumptions.

\textbf{Using published GFuNK performance to describe this companion.} Report only this companion's own calculations and limitations.
