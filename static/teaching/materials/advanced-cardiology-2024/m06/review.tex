\section*{Fourier-mode error analysis of a transport discretization --- review sheet}
Use this after attempting the worked examples and practice. Explain each claim in words before calculating.

\section*{Key ideas}
\begin{itemize}
\item Match equation, boundaries, initial state and state representation in a benchmark.
\item Observed order is measured from a controlled error sequence.
\item Use a fixed spatial model to isolate time error.
\item A zero-sum unstable mode can pass global conservation.
\end{itemize}
\section*{Common errors and repairs}
\textbf{Calling any two closer curves a convergence study.} Specify the reference, error norm, controlled refinement and endpoint.

\textbf{Treating formal order as a universal measured result.} Measure observed order for the actual scheme, boundaries and tested solution.

\section*{Retrieve without your notes}
\begin{itemize}
\item If halving h divides error by eight, what order is observed?
\item What is the checkerboard factor at $\mu$=\allowbreak{}0.5?
\end{itemize}
\section*{Readiness check}
\begin{itemize}
\item Construct an exact periodic transport benchmark with compatible initial and boundary data.
\item Measure observed error order from a controlled refinement table.
\item Separate time error from space error rather than changing both without a reference.
\item Identify an unstable diffusion setting and explain why conservation cannot rescue it.
\end{itemize}
