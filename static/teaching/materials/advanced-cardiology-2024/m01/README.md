# Question, model and observable

Computational cardiology, lecture 1. Run `python demo.py` with Python, NumPy and Matplotlib. No internet access or private files are needed.

The two figures are an original six-region circulation map and a synthetic mean-flow observation map. The same mean output can arise from different rate/stroke-volume pairs. Rates are beats/min, stroke volumes mL/beat, output L/min, pressure drop mmHg and effective resistance mmHg min/L.

The notebook contains a required one-expression implementation scaffold. Its default unfilled cell prints an instruction and leaves the remaining notebook runnable; complete it and run the known check. Guided data are distinct from the original assigned exercises.

The method and model framing are attributed to Hoppensteadt and Peskin, chapter 1. They are illustrative calculations, not patient observations or evidence of clinical adequacy.
