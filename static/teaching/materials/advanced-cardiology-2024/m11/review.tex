\section*{Image coordinates, pixel-cell meshes and geometric sensitivity --- review sheet}
Use this after attempting the worked examples and practice. Explain each claim in words before calculating.

\section*{Key ideas}
\begin{itemize}
\item Physical geometry depends on spacing, origin, direction and index convention.
\item Pixel-cell triangulation can be verified exactly for a fixed mask.
\item Threshold, resampling and mesh refinement are different interventions.
\item Provenance supports reproducibility; independent evidence supports anatomical validation.
\end{itemize}
\section*{Common errors and repairs}
\textbf{Use row/column directly as x/y.} Write the explicit [column,row] geometric vector and apply spacing before direction.

\textbf{Take an equal-area diameter as an anatomical width.} It is one scalar summary; retain local features and topology.

\textbf{Describe the 2D mesh as a completed CFD model.} State the missing domain, boundary, material and solver ingredients.

\section*{Retrieve without your notes}
\begin{itemize}
\item How does doubling both spacings affect area?
\item Which check can an origin error evade?
\item What does a hash fail to establish?
\end{itemize}
\section*{Readiness check}
\begin{itemize}
\item Map a row/column location into physical coordinates with units.
\item Construct a conforming triangular mesh of a synthetic foreground mask and verify its area.
\item Separate threshold sensitivity from mesh refinement and from validation against anatomy.
\item Record enough provenance to reproduce the image-to-geometry calculation.
\end{itemize}
