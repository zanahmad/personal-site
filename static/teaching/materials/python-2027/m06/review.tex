\section*{Embeddings and scaled dot-product attention --- review sheet}
Use this after attempting the worked examples and practice. Explain each claim in words before calculating.

\section*{Key ideas}
\begin{itemize}
\item Array axes distinguish positions from feature coordinates.
\item Queries and keys determine scores; values supply coordinates to mix.
\item Row-normalized attention weights sum to one over allowed keys.
\item Apply a mask inside normalization and reject rows with no permitted keys.
\item A fixed forward pass is distinct from parameter training, generation and scientific validation.
\end{itemize}
\section*{Common errors and repairs}
\textbf{Treating the output vector as token probabilities.} Z contains mixed value coordinates; no vocabulary classifier is supplied.

\textbf{Interpreting invented embeddings as learned meaning.} These coordinates and projection coefficients were chosen by hand.

\textbf{Erasing weights after normalization without rescaling.} Normalize only across permitted keys.

\textbf{Accepting a scientific claim because its explanation sounds plausible.} Specify what the calculation establishes and obtain the appropriate independent evidence for claims outside it.

\section*{Retrieve without your notes}
\begin{itemize}
\item What does softmax return for equal scores over two permitted keys?
\item Why subtract a row maximum before exponentiation?
\item What parameters are learned in this demonstration?
\end{itemize}
