Use this after attempting the worked examples and practice. Explain each claim in words before calculating.

\section*{Key ideas}
\begin{itemize}
\item Names and values need units and a clear meaning.
\item A string containing digits is still text.
\item Assignment uses the values available when it runs.
\item Unit conversion changes numbers according to a relationship.
\item Points, connectors and model predictions are different evidence.
\item A clean ordered run checks notebook dependencies.
\end{itemize}
\section*{Common errors and repairs}
\textbf{Change a label without changing values.} Convert the numbers and update the unit label together.

\textbf{Treat an earlier assignment as automatically refreshed.} Rerun dependent calculations after changing an input.

\textbf{Call the endpoint rate an instantaneous derivative.} It is an average over the stated interval.

\section*{Retrieve without your notes}
\begin{itemize}
\item How many minutes are 210 seconds?
\item Does a shared Celsius-to-kelvin offset change temperature differences?
\item What does restarting a notebook check?
\end{itemize}
\section*{Readiness check}
\begin{itemize}
\item Run a supplied cell or script and distinguish code, output and an error message.
\item Store and print numerical values and text labels without confusing their types.
\item Convert a time and a temperature unit while retaining the scientific meaning.
\item Read a labeled plot and distinguish an observation from an interpolated or modeled value.
\item Restart and rerun a short notebook in order to check reproducibility.
\end{itemize}
