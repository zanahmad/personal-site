\section*{Functions, control flow, and threshold statistics --- review sheet}
Use this after attempting the worked examples and practice. Explain each claim in words before calculating.

\section*{Key ideas}
\begin{itemize}
\item State the scientific rule before choosing a comparison operator.
\item A function returns a result that another calculation can use.
\item Check missingness before numerical comparison.
\item A loop invariant links counters to the observations processed.
\item Zero is a valid time; None means no time has been recorded.
\item Report the denominator and distinguish a recorded time from a modeled crossing.
\end{itemize}
\section*{Common errors and repairs}
\textbf{Treating None as a zero temperature.} Keep a missing category; a replacement would introduce an assumption.

\textbf{Overwriting a first time of zero.} Use an explicit is None sentinel test.

\textbf{Calling 5/9 the fraction among known readings.} There are eight known readings, so that fraction is 5/8.

\textbf{Changing <=\allowbreak{} to < without changing the stated question.} The equality boundary must match the scientific rule.
