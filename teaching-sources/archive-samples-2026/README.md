# Selected teaching samples, October 2026

Four edited public samples from Zan Ahmad’s Fall 2024 HEROIC course and January 2026 EN.553.285 course. The private archive originals are preserved separately; source hashes and curation decisions live in the Vault owner, not in this public repository. No private record, source archive, patient data, homework solution key, or third-party model implementation is included.

`build_samples.py` contains the editable content and emits `samples.json`, four PDFs, a PDF hash manifest, and four Hugo reader pages. Run it with Python and reportlab/pypdf from this repository. Fonts use the Codex bundled DejaVu files; adjust `FONT` for another environment. Final PDFs are in `static/files/teaching-samples`. Runnable Python companions are adjacent. Web typography is confined to the curated and publications templates.

Public revisions correct the original list-length complexity statement, qualify numerical stability and feedback assumptions, and credit Barba/Forsyth and Johansson. The HEROIC project remains a project brief with an external model dependency. Finite differences is explicitly a selection of linear transport and diffusion from a longer tutorial, not a complete replacement of the original course.

The two scientific code companions were executed during release verification. See the Vault record for QA and deployment receipts. PDF page count and hash manifest is regenerated with the PDFs.
